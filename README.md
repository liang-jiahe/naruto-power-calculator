# 火影战力计算器

一个纯前端、非官方的同人工具，包含“战力计算器”“升级时间计算”“抗魔计算器”和“消耗材料查询”四个板块，均可从侧边栏进入。战力板块支持等级、忍魂、天赋、装备、勾玉、饰品与符文、神器、通灵、忍具、秘卷、装扮、称号和头像框等 16 个战力分项；升级板块可推演 140–170 级的升级天数、完成日期与经验来源；抗魔与材料板块用于规划饰品强化和掉落门槛。

在线使用：[GitHub Pages](https://liang-jiahe.github.io/naruto-power-calculator/)

## 功能

- 所有计算均在浏览器本机完成，不上传数据
- 统一的 TypeScript 纯函数计算引擎
- 20–170 级等级收益表、18 种通灵兽数据和 11 档符文共鸣
- 全局收集加成实时联动
- 总战力、可归属面板属性和未归属直接战力分别展示
- 140–170 级升级经验、丰饶、活跃、精英与修罗数据表
- 支持 VIP、超影、每日购体和每周体力礼包的逐日升级推演
- 计算六个饰品部位的强化后抗魔，展示 10 个品级的掉落门槛与目标差距
- 支持饰品名称记录、更换标记、目标选择和独立重置
- 查询破晓、晨曦、旭日、苍穹、云迹五套材料表，汇总绿水、紫星与保护符
- 按“单次消耗 / 此前累计消耗”分组展示材料，支持 +0 到最高 +35 的区间查询
- 战力数据在本机自动保存；升级、抗魔与材料配置只在当前会话中保留，切换板块不丢失输入
- 战力导航默认折叠；顶部下载、导入、公式、PDF 与清空工具栏仅在战力板块显示
- 可直接下载带中文文本和完整录入明细的 PDF 战力报告
- 桌面、平板和手机响应式布局

## 核心公式

```text
生命 × 1
攻击 × 3.5
防御 × 11.6
暴击 / 元素攻击 × 6
抗暴 / 元素防御 × 10

收集倍率 = 1 + 全收集加成 × (1 + 对应属性百分比加成)

单件总抗魔 = 向上取整(基础抗魔 × (1 + 5% × 强化等级))
区间强化材料 = 当前等级 + 1 至目标等级（含）的逐级消耗之和
```

具体模块是否吃收集加成，以页面导出的《公式说明》及 `src/domain/engine.ts` 为准。

## 数据说明

战力等级、通灵、符文共鸣表及升级经验数据依据参考工具中公开呈现的事实性数值整理。升级算法与数据来自本地参考项目 `E:\hyrz`，以独立的 React + TypeScript 组件重新实现；应用代码、状态结构和猫咪主题视觉均独立编写。

抗魔算法、饰品门槛与五套强化材料数据整合自 [meow-magic-calculator](https://github.com/liang-jiahe/meow-magic-calculator)，对应提交 [`d6766f7`](https://github.com/liang-jiahe/meow-magic-calculator/tree/d6766f7aa5295ae367529c3de877e07506ca3651)。原始 Excel 数据表可在该提交的 [`data/source`](https://github.com/liang-jiahe/meow-magic-calculator/tree/d6766f7aa5295ae367529c3de877e07506ca3651/data/source) 追溯。新板块使用原生 React + TypeScript 组件，与原项目样式和状态隔离，不依赖外部页面或运行时请求；运行时材料数据位于 `src/magic/materials-data.ts`。
