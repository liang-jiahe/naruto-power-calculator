# 火影战力计算器

一个纯前端、非官方的同人战力分析工具。支持等级、忍魂、天赋、装备、勾玉、饰品与符文、神器、通灵、忍具、秘卷、装扮、称号和头像框等 16 个战力分项。

在线使用：[GitHub Pages](https://liang-jiahe.github.io/naruto-power-calculator/)

## 功能

- 所有计算均在浏览器本机完成，不上传数据
- 统一的 TypeScript 纯函数计算引擎
- 20–170 级等级收益表、18 种通灵兽数据和 11 档符文共鸣
- 全局收集加成实时联动
- 总战力、可归属面板属性和未归属直接战力分别展示
- 本机自动保存、JSON 导入导出、公式导出和打印为 PDF
- 桌面、平板和手机响应式布局

## 本地开发


```bash

```

## 核心公式

```text
生命 × 1
攻击 × 3.5
防御 × 11.6
暴击 / 元素攻击 × 6
抗暴 / 元素防御 × 10

收集倍率 = 1 + 全收集加成 × (1 + 对应属性百分比加成)
```

具体模块是否吃收集加成，以页面导出的《公式说明》及 `src/domain/engine.ts` 为准。

## 数据说明

等级、通灵和符文共鸣表依据参考计算器中公开呈现的事实性数值整理。应用代码、计算引擎、状态结构和视觉界面均独立编写。

本项目不隶属于、也不代表任何游戏发行商或版权方；数据与算法仅供玩家交流和估算，不构成官方数值承诺。
