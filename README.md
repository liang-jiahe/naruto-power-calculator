# 火影战力计算器

一个纯前端、非官方的同人工具，包含“战力计算器”和“升级时间计算”两个板块。战力板块支持等级、忍魂、天赋、装备、勾玉、饰品与符文、神器、通灵、忍具、秘卷、装扮、称号和头像框等 16 个战力分项；升级板块可推演 140–170 级的升级天数、完成日期与经验来源。

在线使用：[GitHub Pages](https://liang-jiahe.github.io/naruto-power-calculator/)

## 功能

- 所有计算均在浏览器本机完成，不上传数据
- 统一的 TypeScript 纯函数计算引擎
- 20–170 级等级收益表、18 种通灵兽数据和 11 档符文共鸣
- 全局收集加成实时联动
- 总战力、可归属面板属性和未归属直接战力分别展示
- 140–170 级升级经验、丰饶、活跃、精英与修罗数据表
- 支持 VIP、超影、每日购体和每周体力礼包的逐日升级推演
- 战力数据在本机自动保存；升级配置只在当前会话中保留
- 桌面、平板和手机响应式布局

## 核心公式

```text
生命 × 1
攻击 × 3.5
防御 × 11.6
暴击 / 元素攻击 × 6
抗暴 / 元素防御 × 10

收集倍率 = 1 + 全收集加成 × (1 + 对应属性百分比加成)
```

具体模块是否吃收集加成，以页面导出的《公式说明》及 `src/domain/engine.ts` 为准。

## 数据说明

战力等级、通灵、符文共鸣表及升级经验数据依据参考工具中公开呈现的事实性数值整理。升级算法与数据来自本地参考项目 `E:\hyrz`，以独立的 React + TypeScript 组件重新实现；应用代码、状态结构和猫咪主题视觉均独立编写。
